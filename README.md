# Vision Store

Landing page institucional para um estúdio de criação de sites e presença digital.

## Tecnologias

- HTML
- Tailwind CSS via CDN
- Font Awesome

## Proposta

Apresentar serviços de criação de sites, landing pages e presença digital em uma interface responsiva.

## Execução

Abra `index.html` diretamente no navegador.
